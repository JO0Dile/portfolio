## Features

- 🎨 Pastel cool-cute aesthetic with a dynamic 3D scene (Three.js)
- 🤖 Companion robot pet that follows the cursor, blinks, sleeps, and reacts
- 📦 Interactive project modals with live animated app mockups
- 🧪 Lab playground with simulated code + output for each skill category
- ✨ Scroll-driven reveals, sparkles, ripples, and ambient motion
- 📸 Photo mode (press `P`)
- 🎉 Easter eggs (type `dile` or `hammam` anywhere)

## Tech

- HTML, CSS (vanilla — no frameworks)
- Three.js (r128)
- GSAP 3 + ScrollTrigger
- Custom JavaScript modules
