## 04 · Details

A dynamic 3D scene over a pastel palette. A companion robot that follows the
cursor, blinks, sleeps and reacts. Project modals with live animated mockups.
A lab playground running simulated code and output per skill category.
Scroll-driven reveals, sparkles, ripples, ambient motion.

Screen-reader text sits behind every 3D-rendered section, so the page stays
readable without the canvas.

## Local

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>. Opening `index.html` directly works too, unless
your browser blocks ES modules over `file://`.
